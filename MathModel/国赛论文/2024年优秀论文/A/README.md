# 2024 年研究生数学建模竞赛 A 题参考资料

主题：风电场有功功率优化分配

## 资料说明

目前公开渠道中未找到由竞赛组委会正式发布的 2024 A 题优秀论文集。本目录只收录能够核验来源、可以公开下载的完整材料，并区分“解题型论文”“获奖代码”和“学术参考”，避免把赛中付费成品或来源不明的论文标成获奖论文。

## 建议阅读顺序

1. `公开解题论文/考虑通信延迟与测量噪声的风电场有功功率优化调度.pdf`
   - 与赛题四问高度一致，覆盖疲劳损伤、功率分配、卡尔曼滤波、滑动窗口和遗传算法。
   - 适合先了解一套完整论文如何串联四问。
   - 来源：https://doi.org/10.12677/mos.2025.141072

2. `开源获奖代码/2024A国二完整代码/`
   - 作者明确标注为 2024 年华为杯 A 题全国二等奖。
   - 包含四问 MATLAB 代码、派生结果与动画；仓库当前未公开参赛论文正文。
   - 来源：https://github.com/Hanyuyuan6/2024-Huawei-Math-Model-A

3. `学术参考/风力机结构的实时疲劳损伤预测方法.pdf`
   - 对应第一问。核心是将历史残波与新数据串联，实时更新雨流疲劳损伤。
   - 来源：https://doi.org/10.19912/j.0254-0096.tynxb.2024-1010

4. `学术参考/考虑机组疲劳载荷的风电场有功功率优化分配方法.pdf`
   - 对应第三问。重点参考疲劳均衡目标、功率分配约束和优化评价方式。
   - 来源：https://doi.org/10.3390/su17209189

## 使用提醒

- 第一篇是赛题相关的公开期刊论文，不等同于组委会认证的获奖论文。
- 国二仓库的获奖等级来自作者公开说明，适合复现算法，但不要直接复制代码或结论。
- 学术参考用于检查模型的物理合理性和算法依据，不宜照搬成竞赛解答。
- 训练时建议重点比较每份材料对实时性、约束满足、优化前后公平评价和鲁棒性的处理。
