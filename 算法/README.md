# 工程机理与优化算法库

面向你的背景：做过本科板凳龙，熟悉物理建模、微分方程、数值计算和优化。主攻“机理建模—参数辨识—预测—约束优化”，备用“结构化数据预测—决策”。近三年指 2023、2024、2025 年研究生国赛。

## 从哪里开始

1. 阅读 [近三年选题指南](01_近三年选题指南.md)，确定主练与备选题。
2. 阅读 [算法选择与使用](02_常用算法手册.md)，按模型结构选方法。
3. 运行 `python 示例/run_all.py`，查看五个独立教学示例的数值结果。
4. 阅读 [训练和验证清单](03_训练与验证.md)，将示例替换成题目数据。

依赖：Python 3.10+、NumPy、SciPy。安装命令：`python -m pip install -r requirements.txt`。示例全部采用合成数据，不是赛题答案，不证明在真实赛题上有优化效果或满足秒级要求。脚本不下载数据，不改动原赛题与论文。

## 文件结构

| 文件 | 内容 |
|---|---|
| 01_近三年选题指南.md | 18 道题的适配性、门槛、训练顺序 |
| 02_常用算法手册.md | 核心算法、适用条件、Python/MATLAB 对应、常见错误 |
| 03_训练与验证.md | 分阶段训练、开赛筛选、论文实验检查 |
| 示例/ode_identification.py | ODE 求解与物理参数辨识 |
| 示例/constrained_allocation.py | 等式与边界约束下的功率分配、权重扫描 |
| 示例/causal_filter.py | 因果卡尔曼滤波与缺测预测 |
| 示例/risk_path.py | 非负风险栅格上的 Dijkstra 路径搜索 |
| 示例/heat_equation.py | 一维热方程显式差分与稳定性检查 |
| 示例/run_all.py | 运行全部示例并做数值一致性检查 |

优先掌握最小二乘、约束优化、数值积分、因果滤波、基本图搜索和模型验证。在线雨流与多源时空融合列为专项；神经网络、粒子群等不作为默认起点。
