# 2021—2025 研究生数学建模算法学习路线

这份路线按“对你的适配性 × 近五年覆盖面 × 比赛中可落地性”排序。你的优势是物理机理、ODE/PDE、数值计算和优化；需要补齐的是数据验证、预测、图论和空间数据处理。目标不是掌握所有算法，而是形成一条主链和一条备用链。

主链：**机理建模 → 参数辨识 → 状态预测 → 约束优化 → 鲁棒性分析**。

备用链：**数据清洗 → 回归/时间序列 → 指标评价或空间建模 → 图论/组合优化**。

## 一、近五年题目对你的适配性

| 年份 | 优先试题 | 适合你的原因 | 当年应回避或谨慎选择 |
|---|---|---|---|
| 2021 | C 帕金森脑深部刺激；E UWB定位；F机组排班 | C是微分方程、仿真和参数优化；E是最小二乘、异常检测和滤波；F是整数规划与网络优化 | A矩阵压缩专业性强；D偏化学特征与分类 |
| 2022 | E草原放牧；C汽车调序；F物资管理 | E包含机理方程、预测和目标规划；C/F可训练组合优化、选址和路径 | D芯片资源排布专业门槛高；A定位涉及阵列信号专项 |
| 2023 | D区域双碳；C竞赛评审 | D可以用核算、回归、时间序列和情景优化贯通；C适合练统计校正、分配和多目标评价 | A/B为通信与硬件矩阵专项；E/F偏医学或雷达深度学习 |
| 2024 | A风电功率优化；C磁芯损耗；E应急车道；F脉冲星 | A与你最匹配；C适合补回归和双目标；E含交通流和预警；F物理性强但天文坐标门槛高 | B通信专业性强；D需要重型GIS数据工程 |
| 2025 | D低空湍流；F园林美学 | D包含物理指标、时空融合、预测和航路优化；F可作为图论与评价型备用 | A/B专业系统门槛高；C/E依赖图像处理或迁移学习 |

实际比赛优先寻找“物理或工程指标 + 连续状态 + 可标定参数 + 约束决策”的题。题号不代表题型，不预先押A题。

## 二、优秀论文给出的信号

本地现有2021—2024年PDF共147篇，其中2021年44篇、2022年42篇、2023年58篇；2024年目录目前只有3份风电相关公开论文和学术参考。对每篇前五页进行关键词扫描，得到的是“出现该方法的论文数”，包括摘要、正文和文献综述中的提及，只用于判断趋势：

| 方法族 | 提及篇数 | 对备赛的解释 |
|---|---:|---|
| 相关性分析 | 59 | 数据题几乎都需要，但不能代替因果或机理解释 |
| 回归、拟合、最小二乘 | 57 | 是机理参数辨识和数据预测共同的底座 |
| 神经网络/LSTM | 44 | 出现多，但训练成本、泄漏和可解释性风险也高 |
| 聚类 | 38 | 常用于工况划分、选址和样本分组 |
| 多目标/Pareto | 31 | 决策题常见，需要会权重、尺度和敏感性 |
| 树模型 | 31 | 表格数据的实用备用模型，比深度学习更适合临场 |
| 线性/整数规划 | 24 | 调度、分配、选址的标准工具 |
| 遗传算法 | 24 | 常见求解器，但应在建模和标准求解器之后学习 |
| 稳健性/灵敏度 | 22 | 区分完整论文和“只得到一个结果”的关键部分 |
| 信号处理 | 17 | 定位、设备故障、波形题的入口 |
| 微分方程 | 15 | 出现频率不最高，但与你的优势和高质量机理题高度匹配 |
| 粒子群、评价模型 | 各15 | 可备用，不应作为所有题的默认方法 |
| 空间插值/PCA | 各12 | 2024地理、2025湍流等题的重要补充 |
| ARIMA | 11 | 小样本时间序列中仍是强基线 |
| 图论/最短路 | 10 | 物流、航路、路线和分配题的通用能力 |

这些论文最值得学习的是“如何把四问串起来”。算法名称多不等于模型强。每个复杂模型都应与简单基线比较，并给出误差、约束、稳定性和计算时间。

## 三、按重要性逐个学习

完成前七项后，你已经具备比较稳的参赛能力。第八至十一项扩展选题面；第十二项按队友和赛题决定。

### 1. 数据处理、验证与可视化（6—10小时）

学习内容：数据类型和量纲检查、缺失与异常、标准化、时间/分组切分、滚动验证、误差指标、残差图、置信区间、数据泄漏。

必须做到：

- [ ] 能在30分钟内输出数据字典、缺失率、异常值和基础分布图。
- [ ] 知道随机切分、按时间切分和按对象分组切分分别适用于什么情况。
- [ ] 每个预测模型都设置朴素基线；每个优化模型都设置原方案基线。
- [ ] 不在全数据上提前做标准化、特征筛选或插值。

练习：2024 A附件1/2；2024 C实验数据；2023 D历史序列。

### 2. 回归拟合与物理参数辨识（12—18小时）

学习内容：线性/多项式回归、岭回归、非线性最小二乘、带边界参数拟合、稳健损失、参数可辨识性、多初值、Bootstrap区间。

必须做到：

- [ ] 能把经验公式写成 `y=f(x,θ)` 并估计参数θ。
- [ ] 会比较线性基线、物理公式、残差修正三种路线。
- [ ] 检查参数单位、符号、合理区间和外推行为。
- [ ] 报告训练误差、独立验证误差和分工况误差。

练习：2024 A问题二；2024 C斯坦麦茨公式修正；2021 E的UWB最小二乘定位。

### 3. 约束优化：LP/QP/NLP/MILP（16—24小时）

学习内容：决策变量、目标和约束的标准表达；线性规划、二次规划、非线性规划、0-1与混合整数规划；可行性、KKT直觉、SLSQP/SQP、分支定界、最优性间隙。

必须做到：

- [ ] 先证明或数值检查可行域非空。
- [ ] 能把每条自然语言限制翻译成等式或不等式。
- [ ] 优化后逐条报告约束残差，而不只看求解器的“success”。
- [ ] 能说明局部最优、全局最优和启发式较优解的区别。

练习：2024 A问题三；2022 C汽车调序；2021 F机组排班。

### 4. 常微分方程、状态空间与数值求解（10—16小时）

你已有基础，这一项重点补“辨识和验证”，而不是继续刷解析解。

学习内容：守恒/平衡方程、舱室模型、Logistic/SIR、状态空间、RK45、刚性方程、事件检测、稳定点、参数扫描。

必须做到：

- [ ] 从机理画出状态流图，再写方程和边界条件。
- [ ] 检查极限工况、守恒和数值步长收敛。
- [ ] 能把ODE求解器嵌入最小二乘或优化器。
- [ ] 知道何时低阶ODE比PDE更适合四天比赛。

练习：2021 C Hodgkin-Huxley；2022 E草原水分/植被；2024 A风机状态模型。

### 5. 时间序列预测（12—18小时）

学习顺序：持续值/季节朴素 → 移动平均和指数平滑 → AR/ARIMA → 多变量回归或状态空间。灰色GM(1,1)只作为极小样本备用。

必须做到：

- [ ] 使用滚动预测验证，禁止未来数据泄漏。
- [ ] 检查趋势、季节性、自相关和残差白噪声。
- [ ] 输出预测区间，并和持续值基线比较。
- [ ] 样本不足时不直接使用LSTM。

练习：2022 E土壤指标；2023 D人口、能源和碳排放；2024 E交通流预警。

### 6. 多目标优化、灵敏度与鲁棒性（10—16小时）

学习内容：指标同向化和尺度化、加权和、epsilon约束、Pareto前沿、权重敏感性、局部灵敏度、Monte Carlo扰动、情景分析、鲁棒目标。

必须做到：

- [ ] 权重变化时能画出目标之间的权衡曲线。
- [ ] 解释权重的业务意义，不用AHP自动替代判断。
- [ ] 对关键参数、噪声和初值做扰动实验。
- [ ] 区分预测不确定性、参数不确定性和优化求解误差。

练习：2024 A主轴/塔架双目标；2024 C损耗/传输能力；2023 D多情景路径。

### 7. 图论与组合优化（14—20小时）

学习内容：图的构造、Dijkstra、A*、最小生成树、二分图匹配、指派、最大流/最小费用流、设施选址、车辆路径、动态规划和贪心基线。

必须做到：

- [ ] 能把空间或任务关系转成节点、边、容量和代价。
- [ ] 能判断最短路、指派、网络流和MILP哪个结构最合适。
- [ ] A*启发函数满足可采纳性；动态风险场把时间放进状态。
- [ ] 组合问题先构造合法解，再谈遗传算法。

练习：2022 F选址与配送；2023 C交叉分发；2025 D/F航路或游览路线。

### 8. 因果滤波与基础信号处理（12—18小时）

学习内容：滑动平均、Savitzky-Golay、小波去噪、FFT/Welch、包络谱、互相关时延、卡尔曼滤波、缺测和延迟观测。

必须做到：

- [ ] 明确采样率、窗长、频率分辨率和混叠。
- [ ] 在线任务只使用当前及历史数据。
- [ ] 卡尔曼滤波能写出状态方程、观测方程及Q/R含义。
- [ ] 用滤波前后误差和相位延迟评价效果。

练习：2021 E UWB；2024 A问题四；2025 E只做基础轴承频谱，不进入迁移学习。

### 9. 空间插值、多源融合与数据同化（14—22小时）

学习内容：坐标与网格、最近邻/线性/IDW/RBF/Kriging、交叉验证、空间掩膜、多分辨率重采样、加权最小二乘、3DVAR直觉、时空状态更新。

必须做到：

- [ ] 统一坐标、单位、时间戳和空间分辨率。
- [ ] 插值验证按空间留点，不随机打散相邻格点。
- [ ] 标明观测覆盖区和外推区，输出可靠性或不确定性图。
- [ ] 能把空间风险场交给A*或Dijkstra。

练习：2024 D；2025 D。这个模块决定你能否真正选择2025 D型题。

### 10. PCA、聚类和评价模型（8—12小时）

学习内容：相关性、PCA、K-means/层次聚类、熵权、TOPSIS、模糊综合评价；同时学习指标构造和稳定性检验。

必须做到：

- [ ] 先解释指标含义，再标准化和赋权。
- [ ] 聚类数有轮廓系数、稳定性或业务依据。
- [ ] PCA解释方差、载荷和成分含义。
- [ ] 评价结果接受权重扰动和排序稳定性检验。

练习：2022 E草原评价；2023 C竞赛评审；2025 F园林美学。

### 11. 表格数据的基础机器学习（12—18小时）

学习内容：岭/Elastic Net、随机森林、XGBoost或LightGBM、SVM；交叉验证、类别不平衡、特征重要性和SHAP。掌握其中两类即可。

必须做到：

- [ ] 先打败线性/朴素基线，再保留复杂模型。
- [ ] 管道化预处理，避免测试集信息泄漏。
- [ ] 小样本报告交叉验证波动，不只报一次最高分。
- [ ] 把机器学习作为数据关系模型或机理残差模型。

练习：2024 C问题四；2023 E可只练表格数据部分。该项用于扩大备选题面，不改变你的主攻方向。

### 12. 元启发式与深度学习（最后学习）

先学差分进化，再选遗传算法、粒子群或模拟退火中的一种。需要会编码、可行解修复、固定随机种子、重复实验、收敛曲线和与标准求解器比较。

CNN、U-Net、LSTM、迁移学习只在队友或赛题明确需要时专项学习。2025 C/E型题需要稳定的数据管线、算力和调参经验，临场调用现成网络很难形成可靠优势。

## 四、推荐的学习节奏

每个模块只在完成下面四件事后打勾：

1. 一页公式与适用条件笔记；
2. 一个能独立运行的最小代码；
3. 一道历年题的小问复现；
4. 一张基线对照表和一项失败案例说明。

建议顺序：

- 第一阶段：1 → 2 → 3 → 4，建立主链。
- 第二阶段：5 → 6 → 7，形成完整参赛能力。
- 第三阶段：8 → 9 → 10，扩大工程与备用题覆盖面。
- 第四阶段：11 → 12，按队伍分工选学。

若每周投入8—10小时，前七项约需10—12周。你在ODE和优化方面已有基础，可以把节省的时间放在数据验证、时间序列、图论和空间处理上。

## 五、代表论文阅读顺序

只读摘要、问题分析、核心模型、结果评价和优缺点，第一遍不要陷入所有推导。

1. `2021/C/C21102860153.pdf`：HH微分方程、参数扫描、刺激参数优化；看机理如何贯穿多问。
2. `2021/数模之星/E21103860005.pdf`：异常处理、聚类、最小二乘、定位修正；看数据清洗如何服务物理几何。
3. `2022/E/E22100160013.pdf`：微分方程、ARIMA、PCA和目标规划；辨别哪些模型真正串联、哪些只是并列。
4. `2022/C/C22103190082.pdf`：0-1整数规划、动态仿真和遗传算法；重点看合法解编码与约束处理。
5. `2022/F/F22106150018.pdf`：聚类选址、Dijkstra和车辆路径；学习从数据到网络图的抽象。
6. `2023/C/C23104080013.pdf`：交叉分发、评分校正和多目标评价；作为非物理备用题范本。
7. `2023/D/D23100060041.pdf`与`D23104860011.pdf`：回归、ARIMA、灰色模型、ODE和情景规划；重点比较简单模型与模型堆叠。
8. `2024/A/公开解题论文/考虑通信延迟与测量噪声的风电场有功功率优化调度.pdf`：卡尔曼、时间窗口、鲁棒调度；同时检查实时性和约束验证是否充分。

论文均位于 `MathModel/国赛论文/对应年份优秀论文/`。配合 `02_常用算法手册.md` 查看算法边界，配合 `03_训练与验证.md` 完成实验检查。

## 六、开赛选题规则

开赛后先筛两个候选题，每题限时45分钟：读取附件、做第一问最小基线、列出后续问题的输入输出和关键风险。按下列五项各0—5分评分：

| 维度 | 5分标准 |
|---|---|
| 个人/团队能力匹配 | 核心方法至少一人完整实现过 |
| 数据可控性 | 30分钟内读通并画出关键变量 |
| 全题连贯性 | 前问输出能自然进入后问 |
| 可验证性 | 每问都有参考、基线或物理边界 |
| 完成把握 | 能明确列出论文所需表格、图和附件 |

专业名词多不是自动弃题条件。第一问的数据、核心公式或输出形式无法在限定时间内说明，才应降低优先级。最终选择总分高且“数据可控性、完成把握”均不低于3分的题。
