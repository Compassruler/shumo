## 2. 第(1)问：动态控制结果与表4

### 2.1 控制器设计要点

按建模文档第2–3章的**分层反馈**结构实现（`dynamic_model.Controller`）：

1. **反馈信号**：实时采集单片温度 T_k、电压 V_k，一阶低通滤波 + 速率估计；
2. **参考轨迹**：端部片目标 4℃（冰点+热裕度），中心/近端目标 18~20℃（维持向端部端板热汇的片间导热支撑）；参考斜率按最大可行加热速率 v_max=2 K/s 规划，**t_plan 随初始温度自适应**（工况1→25 s、工况2→14.5 s、工况3→21 s）；
3. **前馈 + 增量式 PI** 跟踪参考轨迹；
4. **冰堵安全增强**（R_ice 越限即强制加力，硬保护 ε<0.99、V≥0.30）；
5. **近成功渐缩 + 全局停止**（全部成功并保持 t_hold=2 s 后统一关断）。

### 2.3 结果解读

**(1) 三工况均可行，能耗排序正确。** 动态控制与恒功率在三种工况下都满足全部约束（最低电压均 >0.60 V、最大冰分数均 <0.02，远优于安全阈值 V≥0.30、ε<0.99）。辅助加热总能耗满足 **工况1 > 工况3 > 工况2**，与"预冷越充分（初温越低）能耗越高"的物理预期一致（建模文档 5.3 节定性判断被定量验证）。

**(2) 动态控制能耗略高于恒功率，机理上可预期。** 对工况1，动态 E_aux=3566 J 较恒功率 C 的 2977 J 高约 20%。这不是控制器"失效"，而是该强耦合系统的**能量最优控制本身呈 bang-off 形态**（见第3节）：最优解是"每片恒定功率、达到成功判据即停"，而问题3 已通过离线搜索得到该最优的恒功率实现 C=[1,1,0.6245,1,1]。动态反馈作为其"平滑、鲁棒"实现，因引入跟踪裕度（端部目标 4℃ 高于成功阈值 0℃）与对中心/近端片的有源维持，存在少量能量开销。

**(3) 动态控制的真正价值在于自适应与鲁棒。** 恒功率 C 是**针对 −30℃ 均匀工况离线优化**得到的开环功率分配；换一个预冷工况或受扰动时需重新整定。动态控制则：
- **无需逐工况离线重优化**——同一套反馈律 + 自适应 t_plan 在三工况下自动适配初始场（工况2、3 的 t_plan 自动缩短到 14.5 s、21 s，避免"龟速爬升"）；
- **安全反馈硬保护**——冰堵/低压先兆即强制加力（式 4.35），保证 ε<0.99、V≥0.30 不违反；
- **抑制工况1 的温度非均匀性**——ΔT_max 由恒功率的 25.2 K 降至 22.7 K，端部/中心一致性改善。

## 3. 机理：为何恒功率 C 接近能量最优（bang-off）

这是问题4最值得强调的物理结论。整堆由 **2 块大热容端板（单位面积热容 39500 J·m⁻²K⁻¹，占整堆显热约 81%）** 与高导热双极板（k=95 W·m⁻¹K⁻¹）构成强耦合热网络。

**(1) 端板是主导热沉。** 端部单电池要越过 0℃，必须先焐热相邻端板。能量平衡核算（工况1）表明：辅助加热 2977 J 中，显热 3049 J，对流损失仅 90 J，反应产热 163 J 起助力；显热的主体是端板被焐热（终温约 −24℃，仅升 ~5.7 K，但热容巨大）。

**(2) 中心片"过热"是储能支撑而非浪费。** 恒功率 C 成功时中心片浮到 ~25℃（其被邻居隔热、又获反应产热），这团余热作为**导热储备**持续经 2/4 片向端部补热，使端部快速越过 0℃、少焐端板。因此 C 的空间分配 **[1, 1, 0.6245, 1, 1]**（端部与近端满功率、中心降功率）恰是全局最优——2/4 片满功率充当"导热放大器"，同时向端部与中心供能。

**(3) PMP 视角（建模文档 4.4 节）。** 把 q_k(t) 作为控制量时，Hamilton 函数对 q_k 线性，极小值原理给出 **bang–off（0/上限）+ 边界弧**的开关形态：仅在"阻止冰堵/跨越冰点的边际收益为正"的片与时加热，其余关闭。恒功率 C 正是该开关解的直接实现；动态反馈则是其**平滑实现**——换取对模型误差、初场偏差、测量噪声的鲁棒，代价是少量跟踪能耗。

> 这一分析解释了实验现象：逐片"局部目标"的动态控制器若把中心/近端片按局部温度削减（切断向端部的导热链），能耗反而上升；必须保留近端片满功率的"导热放大"角色（见 `code/tune_controller.py` 的参数扫描记录）。

## 4. 第(2)问：10~100 min 预冷下的恒功率冷启动

（图 `figures/03_预冷10到100min扫描.png`）

**规律：**
1. **全区间可成功启动**。因恒功率 C 是针对 −30℃（最冷）整定的，故对一切更暖的预冷场都足以启动，10~100 min 内不存在"临界失败冷却时间"；
2. **能耗/时间/温差随 τ_c 单调上升并趋于极限**。初温越冷，显热与端板热沉吸收越大，E_aux 由 5.8 J（10 min）单调增至 2919 J（100 min），并趋于 −30℃ 均匀场的 2977 J；t_s 由 0.05 s 增至 25.3 s；
3. **温差先由预冷梯度主导、后由端部效应主导**。τ_c 较小时 ΔT_max 主要由预冷非均匀性贡献；随 τ_c 增大预冷梯度减小，但整体更冷、启动中端部对流/端板热汇重新拉开温差，ΔT_max 单调升至 ~24.8 K，最危险片始终为端部第 1、5 片。

## 5. 能量守恒与模型一致性检验

1. **能量闭合**：所有工况/扫描点 `energy_residual_J = E_sensible − (E_aux + E_gen + E_phase − E_loss)` 均 < 1e-10 J（相对 10³ J 量级为 1e-13 量级），满足"反应产热 + 辅助加热 = 显热增加 + 对流散热 + 相变潜热"的平衡。
2. **与问题3 一致性**：动态模型取均匀 −30℃ 初场、令控制器退化为恒功率 C 时，E_aux=2977 J、t_s=25.8 s，与问题3 优化结果（2975 J、25.73 s）**相对误差 < 0.1%**，验证了问题4 模型与问题3 口径一致。
3. **预冷场一致性**：precool.py 复现的 20/40 min 温度场与建模文档 1.6 节表格吻合（差值 < 0.05℃）。

## 6. 结论

1. **预冷模型**（第(2)问前半）：一维有限体积 + 后向欧拉模型给出 10~100 min 的预冷温度场族，物理上由"慢模态（均匀降温，τ≈20.3 min）+ 快模态（非均匀，秒级衰减）"刻画，Bi≈0.09 说明基准参数下预冷场接近均匀。
2. **动态控制**（第(1)问）：以 T_k、V_k 为反馈的分层控制器在三工况下均可行、能耗排序正确；相较问题3 恒功率 C 能耗略高（约 20%，工况1），但其**免离线重优化、安全反馈硬保护、改善温度一致性**的优点是恒功率开环策略所不具备的，属于"以少量能耗换鲁棒性"的合理设计取舍。
3. **恒功率 C 的近最优性**：机理分析表明该强耦合系统的能量最优控制为 bang-off 形态，问题3 的 C 已实现之；动态控制是这一开关最优解的平滑鲁棒实现——这一结论由 PMP 与能量平衡共同支撑。
4. **预冷程度的影响**（第(2)问后半）：10~100 min 预冷下恒功率 C 全部可启动，能耗/时间/温差随 τ_c 单调上升并趋于 −30℃ 极限，为"预冷程度—冷启动代价"的定量权衡提供了依据。
