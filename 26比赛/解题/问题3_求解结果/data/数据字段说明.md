# 问题三数据字段与比较范围

- final_controls.json、summary_results.csv、表4_问题三主结果.csv 保留原主方案：P 加热25.71358180294 s，E=3214.197725367 J；C 加热25.73467806466 s，E=2975.257904282 J。P 原停止温度容差为10^-4 ℃，C约10^-7 ℃。
- event_convergence.csv 为固定上述功率、各离散设置独立定位温度首次过零的补充验证，统一温度容差10^-7 ℃，不重优化。该独立检查允许持续加热到各自事件，因此不能把其粗网格时刻写成原固定关热方案的实际成功时刻。
- summary_results.csv、postload_verification.csv 新增 first_crossing_s、first_crossing_tolerance_C、heat_off_s、first_crossing_scope。原 startup_s、first_success_s 保留兼容；R 的旧值约51.93 s受旧P型关热门控约束，不能表示物理首次过零。
- convergence.csv 的新增 first_crossing_scope=constant_heater_event_check。其中 first_crossing_s 来自该网格的独立恒加热事件检查；其余原状态列仍对应固定原功率及关热时刻的轨迹，二者是不同验证问题。
- 正式网格下新增 P/R first_crossing_s=25.7134510189 s、C=25.7346780647 s。P与原主表相差0.000131 s来自停止温度容差变化，不替换主表结果。R实际 heat_off_s=51.9253924107 s，关热端板−13.764824 ℃；终点148.592059077 s的端板−0.580953 ℃不得误称关热状态。
- trajectory_*.csv 保持原计算的时刻、状态和控制记录。稀疏输出点不用于重新插值判定首次过零，事件时刻另由单步重积分二分确定。P_postload和R采用本文选定的加载曲线作有限96.6667 s窗口验证；题目未对P强制此曲线。
- trajectory中的 cellN_ice_bulk 与 summary中的 max_ice_bulk 均为局部控制体冰体积分数最大值（含膜），并非MEA体积平均。cellN_pore_ice_bulk只检查多孔层，cellN_pore_ice_saturation是局部冰体积分数除以对应干燥孔隙率后取最大值。
- C 主结果最大局部冰分数0.0123394187位于膜内；终端最大孔隙冰饱和度0.0178357965。平均冰量必须由 final_fields_C.csv 按各控制体dx加权另算，不可直接把max_ice_bulk改名为平均量。
- sensitivity.csv中的kf取0.1倍及10倍基准，两端相差100倍；它固定功率并补偿加热时间，不代表原固定关热策略在扰动下的鲁棒通过率。
