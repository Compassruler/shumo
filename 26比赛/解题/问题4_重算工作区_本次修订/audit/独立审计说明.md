# 问题四独立审计说明

本说明依据原题 DOCX 的正文与数学公式邻接文本、问题四建模推导、旧问题四代码和问题三经核验的模型实现。仅审计，不修改旧输出或主程序。

## 一、推荐保留的继承关系

- 水/气体/相变/电化学内核：`问题3_求解结果/code/fast_cell.py`。`diagnostics` 对全 MEA 局部最大冰体积分数、仅多孔层局部最大冰体积分数、膜冰、孔隙冰饱和度分别输出；不得混淆。
- 七节点热网络与单步推进：`问题3_求解结果/code/aux_model.py` 的 `network/evaluate/advance`。保持双极板总数六块：端片各 1.5 块、内部各一块；端板独立两个节点，不能又并入端片热容。
- 问题三基准：`q=(1,1,0.6245115587719579,1,1) W/cm²`，统一 `j(t)=min(0.005t,0.3) A/cm²`，电热丝面积每片 25 cm²。对非均匀场保留功率分配，仅首次成功时间重新计算。
- 主表采用首次成功窗口 `[0,t_s]`；保持时间/关热后验证应另表明确，否则不同控制方案比较不公平。

## 二、建模推导须解释或修正的问题

1. 式 (4.3) Robin 条件符号写反。沿全局 x 正向，左端应为 `k T_x(0)=h(T(0)-Tamb)`，右端应为 `-k T_x(L)=h(T(L)-Tamb)`。旧有限体积离散实际使用 `h(Tamb-T)`，方向正确。
2. 式 (4.34) 若按上一周期实际功率再加完整前馈，会重复积累前馈。应保留独立 PI 修正状态，或仅累加前馈增量。
3. 先安全增强后渐缩，会把刚增强的安全功率重新乘到零。安全增强必须在渐缩之后取 `max`，成功停机是另一个有严格条件的状态。
4. 式 (4.45) 附近的最大温差定义写成了跨时全局极差。反映一致性的指标应为 `max_t [max_k T_k(t)-min_k T_k(t)]`，主表统计五片，包含端板的温差另列。
5. PMP 的控制线性性只给出开关/边界弧的必要结构，不能证明问题三恒定中心功率 0.6245 是动态空间全局最优。离线有限次搜索应称“该参数化策略类内搜索得到的最优可行解”。
6. 原题写 40 min 的非均匀更明显，但从均匀 25 ℃被动冷却至均匀 -30 ℃的空间温差不可能一直增强。给定参数下计算到 20、40 min 均已经进入慢模态，40 min 的绝对梯度较小；应如实报告，不人为放大。
7. 式 (4.6) 的预冷等效物性与已验证问题三物性不相同。按 Q3 内核初态逐层独立计算：`C_MEA=50.22752715 J/(m² K)`、`R_MEA=0.002810469146 m² K/W`、`k_MEA=0.11624394 W/(m K)`、`g_c=353.16698 W/(m² K)`、`g_E=568.30435 W/(m² K)`、`C_stack=97451.29764 J/(m² K)`。Q4 推导采用 `C_MEA≈60.8`、`k_MEA≈0.296`，源于另一种材料等效口径。需明确主模型选择及差异，不能声称完全一致。旧预冷还用双极板 `rho cp=1.517e6`，而精确乘积为 `1980×766=1516680`。
8. 预冷端板外表面对流、启动继承问题二端电池对流是题目阶段模型解释；两者应明确说明，并可提供对流位置敏感性。

## 三、旧代码必须修复的问题

| 问题 | 后果 | 建议 |
|---|---|---|
| `Controller.stopped` 置位后没有在后续 step 最先锁定零功率 | 成功后回落会重新加热，但代码仍按第一次 stop 后 10 s 退出 | 关断状态吸收，继续验证时严格 q=0；如果允许再启动需单独定义策略 |
| 动态 `t_stop=t` 在推进一整步后才记录 | 关热时刻延迟一个 dt | 记录实际控制切换时刻 |
| 恒功率只统计到 t_s，动态统计至 t_stop+10 s | 能量、电压、冰、温差窗口不同 | 主表统一首次成功，后验独立表 |
| 动态首次成功仅用当步 V/ice，恒功率用历史约束 | 已有不安全经历的动态解仍会被记首次成功 | 路径约束统一累积判断 |
| 动态结果键 `t_first_s`，CSV 列 `first_success_s` | 主表动态启动时间空白 | 统一字段 schema |
| 初温全部>0 仍先推进一步 | 10 min 点出现 0.05 s、5.8 J 伪成本 | 在 t=0 检查成功并输出零时间零能耗 |
| 恒功率 `horizon=th if th>0 else post` | 加热后 post 验证参数失效 | horizon 与关热时刻独立，分段对齐 th 与加载拐点 |
| Q4 删除 Q3 的 `j/jlim`、孔隙率、kappa、库存正性检查 | 截断公式可能掩盖失效状态 | 继承完整物理可行性诊断 |
| `rT` 被计算但没有进入动作，`eps_warn` 未使用 | 不完整满足题目“识别温升不足”要求 | 输出状态机指标与实际动作，触发分支可独立测试 |
| 加权风险阈值 0.7，冰分数和电压下降各被截断 | 即使 V=0.30、冰很少仍可能风险<0.7，无增强 | 以低压/高冰任一硬预警优先覆盖，加权指标仅作连续调节 |
| 模型冰量直接反馈，没有电压校正或独立观测器 | 与文档软测量实现不一致 | 明确是模型软测量，或实现有界残差校正，不把真值装成实际传感器 |
| 预冷扫描未精确截断到请求采样时刻 | dt 不整除采样时刻时输出后一个时间层 | 对齐采样事件，或用矩阵指数精确解 |

## 四、能量和水量检验的口径

- 内部导热矩阵的行和仅剩环境换热；无对流时总内部导热应抵消。
- 电热丝电能独立按 `25 sum_k sum_n q_kn Δt_n` 计算，与热方程累计输入核对，不能只核对同一变量的拷贝。
- 原 `advance` 的“显热增量”是离散 `sum C(X_new) ΔT`，残差近机器零证明该离散热方程代数闭合；由于水库存改变热容，它不等于简单端点 `C(T)T` 差，且未显式含所有携水显焓输运。报告应称“离散能量收支残差”，不据此声称全部真实热物理误差为零。
- 水量可独立核对 `库存终值−初值−累计生成+边界流出`。保存累计产水、边界排水、终态库存及残差。
- 网格/步长检验应固定最终控制参数，避免把再优化导致的变化误当数值收敛。
- 安全增强规则不自动构成严格控制不变集证明；只能说“本组工况与扰动试验内约束均满足”。

## 五、建议最小验证集

1. 均匀 -30 ℃、固定 Q3 功率精细重算对齐 Q3 25.73 s、2975.3 J 的结果。
2. 预冷线性系统：镜面对称、最大最小原则、能量衰减、投影前后热容加权能量一致。
3. t=0 已成功、q=0、五路独立非对称输入、关热后功率严格为零、控制器预警优先级。
4. 所有工作 CSV 的积分能量与 summary 一致；包括 0 行、最终事件行、五片全部温度/电压/冰量/功率。
5. 正式三工况与代表性扫描点做步长/网格加密；每个输出表明窗口。
6. 固定控制参数的环境换热/片间热阻/相变速率/测量扰动，记录是否可行，避免用没有试验的“鲁棒”形容。
