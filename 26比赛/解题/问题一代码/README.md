# 第一问一维单电池瞬态自冷启动计算

本目录实现上一级《问题一建模流程_符号与来源核对版.md》的 M1–M53，读取附件一参数和附件二两个工作表的 **F列电流密度（A/m²）**。F列已经换算过单位，不再次乘10000。原始 Word、Excel 和建模 Markdown 均不改动。

## 运行

在本目录的 PowerShell 中执行：

```powershell
./run.ps1
```

若系统禁止运行 PowerShell 脚本，可直接执行同目录 `run.bat`，参数完全相同。

默认复用 `results/calibration.json` 中已经完成的标定；没有该文件时先标定。重新校准并检查网格与时间收敛：

```powershell
./run.ps1 --fit --verify
```

只使用 `params.py` 中的初始猜测作诊断，输出到独立目录：

```powershell
./run.ps1 --no-fit --output baseline_results
```

其他电脑在 Python 环境安装 `requirements.txt` 后运行 `python run_question1.py`。本机的 `run.ps1` 使用已准备的 Python 3.12；`.python_deps` 是本次本机安装的数值计算依赖，不是模型源代码。

## 模型口径

质量域为 aGDL— aCL—PEM—cCL—cGDL；热域增加左右各2 mm双极板。主平均温度为整个热域按网格厚度加权的空间平均，并同时输出MEA平均温度。非均匀网格不能直接对节点温度求算术平均。

多孔层积分总水 `mw` 和冰 `mi`，由 M6 的解析联立关系计算 `mv`、`ml` 和剩余气孔率。PEM内同一个 `mw` 表示吸附水，不进行孔隙汽液冰分配。冻结与融化只在冰方程中改变相态，总水方程不重复扣除冻结水。气体积分的是孔隙率乘气相摩尔浓度的库存。

冰通过剩余气孔率修正扩散系数，并通过 `(1-si)**3.5` 修正阴极有效反应面积。题目式（9）冰体积分数是 `mi/rho_ice`，不是 `mi/(rho_ice*eps0)`。主冰曲线取每个时刻计算域内的空间最大值。

温度和电压都是模型输出。反应热使用模型电压 `j*(1.48-V)`，无辅助加热；相变热为 `Lf*(rf-rm)`。膜—CL水界面按 M43 求解同一个守恒通量，不强制两种介质的质量浓度相等。

## 校准与解释限制

按原Markdown的 M50–M51，用−20℃完整184点同时拟合电压和温度，只校准参考交换电流密度 `j0_ref` 与一阶冻结速率 `k_freeze`。残差以该训练序列标准差归一化；固定参数后计算−25℃作为留出工况。每次参数评估都重新积分整个状态方程。

`params.py` 中的 `j0_ref=0.01` 和 `k_freeze=1` 是优化初猜。正式标定值另存 `results/calibration.json`，避免把拟合值冒充附件物性。`km=kf` 是原建模文件的假设，两组负温实验无法验证融化阶段。固定交换电流密度下的冻结速率扰动只是敏感性诊断，不是置信区间或唯一可辨识性的证明。

附件二没有冰量观测，因此冰量曲线只能称为模型预测。题面没有统一5%误差限，程序如实报告误差，不自动宣布验证通过。两组温度在观测时段内均低于0℃，不能将完成36.6秒计算视为已证明冷启动成功。

附件一面积25 cm²与附件二电流/电流密度隐含面积不一致。按本次指定，F列优先；B列电流只用于审计。新增双极板热域、CL结合水省略、等效未冻水扩散、吸水平衡低温外推等，均保留原MD的假设身份。

积分器允许有限的数值试探，但失效状态不得用截断后的小正孔隙率或电导率继续冒充正常预测。提前终止时只导出有效区间，后续表格留空并记录原因。

数值方法说明可参阅 [SciPy刚性初值问题求解器](https://docs.scipy.org/doc/scipy/reference/generated/scipy.integrate.solve_ivp.html) 与 [非线性最小二乘](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.least_squares.html)。最终数值结论以本次实际生成的结果说明和检查文件为准。
