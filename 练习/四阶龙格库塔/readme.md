# MATLAB `ode45` 求解常微分方程
适用于一阶常微分方程，有二阶微分方程需要先进行降阶处理。

ode45_test.m 是二阶微分方程，不与时间有关。

def——q1_1.m 是一阶微分方程，与时间有关。

本文件夹用两个例子演示如何将高阶常微分方程降阶为一阶状态方程组，再使用 MATLAB 的 `ode45` 进行数值求解。

`ode45` 采用自适应步长的 Dormand–Prince 4(5) 阶显式龙格–库塔算法，适合求解一般的非刚性常微分方程。它接收的模型必须写成

$$
\dot{\boldsymbol y}=F(t,\boldsymbol y)
$$

的形式。高阶微分方程需要先引入状态变量，转化为一阶方程组。

## `ode45_test.m`

这是一个可以直接运行的基础示例，求解二阶非线性方程

$$
y''-(1-y^2)y'+2y=0,
\qquad y(0)=2,\quad y'(0)=0.
$$

令 $y_1=y$、$y_2=y'$，可得

$$
\begin{cases}
y_1'=y_2,\\
y_2'=(1-y_1^2)y_2-2y_1.
\end{cases}
$$

程序在 $0\sim5$ 秒内调用 `ode45` 求解，并绘制两个状态量 $y$ 和 $y'$ 随时间的变化。方程右端没有显式出现时间 `t`，因此它属于自治系统，但解仍然是时间的函数。

文件中还保留了一个被注释的一阶线性方程示例 $y'-y=x$，取消注释并启用对应函数后即可运行。

## `def_q1_1.m`

这是一个微分方程函数，用来描述浮子与振子组成的两自由度受迫振动系统。状态向量为

$$
\boldsymbol y=[x_f,\dot x_f,x_z,\dot x_z]^\mathsf T,
$$

其中 $x_f$、$x_z$ 分别表示浮子和振子的位移。程序把两个二阶动力学方程降阶为四个一阶方程，考虑了浮力恢复项、流体阻尼、弹簧力、相对速度阻尼以及周期外力

$$
f\cos(\omega t).
$$

由于周期外力显式包含 `t`，该模型属于非自治时变系统。这个文件只负责根据当前的 `t` 和 `y` 计算状态导数，本身不会完成整个时间区间的求解，可在主脚本中调用：

```matlab
tspan = [0, 40];
y0 = [0, 0, 0, 0];
[t, y] = ode45(@def_q1_1, tspan, y0);

plot(t, y(:,1), t, y(:,3));
legend('浮子位移 x_f', '振子位移 x_z');
xlabel('时间 t / s');
ylabel('位移 / m');
grid on
```

求解结果 `y` 有四列，依次对应 $x_f$、$\dot x_f$、$x_z$ 和 $\dot x_z$。
