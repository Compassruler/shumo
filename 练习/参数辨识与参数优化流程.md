# 参数辨识与参数优化流程

## 1. 首先判断参数属于哪一类

拿到一个含参数的数学模型后，先回答下面的问题：

```text
这个参数是真实存在但数值未知，还是可以人为选择？
│
├─ 真实存在但未知
│  例如阻尼系数、刚度、衰减率、传染率
│  → 参数辨识：根据观测数据反推参数
│
└─ 可以人为选择
   例如控制系数、设备容量、阻尼器设置
   → 参数优化：根据功率、成本或收益直接寻优
```

最小二乘是一种目标函数，网格搜索、`fminbnd`、`fmincon`、PSO和GA是寻找最优参数的方法。并非所有参数寻优都需要最小二乘。

---

## 2. 参数辨识流程

### 适用问题

已知模型结构和观测数据，需要反推出模型中的未知物理参数。例如，根据浮子位移数据辨识阻尼系数 $a_1$。

### 数学模型

设待辨识参数为

$$
\boldsymbol\theta=[a_1,k,c_w].
$$

模型预测值为

$$
\hat x(t_i;\boldsymbol\theta),
$$

观测值为 $x_i$，则残差为

$$
r_i(\boldsymbol\theta)
=\hat x(t_i;\boldsymbol\theta)-x_i.
$$

可以建立普通最小二乘目标：

$$
\min_{\boldsymbol\theta}J(\boldsymbol\theta)
=\frac1n\sum_{i=1}^{n}r_i^2(\boldsymbol\theta).
$$

若不同观测点的可靠程度不同，可以使用加权最小二乘：

$$
\min_{\boldsymbol\theta}J(\boldsymbol\theta)
=\frac1n\sum_{i=1}^{n}w_i r_i^2(\boldsymbol\theta).
$$

### 计算流程

```text
整理观测数据
      ↓
确定待辨识参数及其物理范围
      ↓
给定一组候选参数
      ↓
用 ode45/ode15s 求解动力学模型
      ↓
在观测时刻提取模型预测值
      ↓
计算残差和目标函数
      ↓
优化算法更新参数
      ↓
满足收敛条件后输出参数
      ↓
残差、拟合优度和灵敏度检验
```

### MATLAB目标函数框架

```matlab
function J = identification_objective(theta, t_data, x_data, y0)

    [~, y] = ode45( ...
        @(t,y) dynamic_model(t, y, theta), ...
        t_data, y0);

    x_pred = y(:,1);
    residual = x_pred - x_data;
    J = mean(residual.^2);
end
```

然后可以选择不同的寻优算法：

```matlab
fun = @(theta) identification_objective( ...
    theta, t_data, x_data, y0);

% 单参数有界优化
theta_best = fminbnd(fun, lb, ub);

% 多参数约束优化
theta_best = fmincon(fun, theta0, ...
    [], [], [], [], lb, ub);

% 多参数全局搜索
theta_best = particleswarm(fun, nvars, lb, ub);
```

如果直接使用非线性最小二乘，也可以选择：

```matlab
theta_best = lsqcurvefit( ...
    @model_output, theta0, t_data, x_data, lb, ub);
```

## 3. 参数优化流程

### 适用问题

参数可以人为调节，需要寻找使系统性能最好的取值。例如，选择阻尼系数 $a_1$，使平均输出功率最大。

这种问题不需要先构造最小二乘误差，直接把性能指标作为目标函数：

$$
a_1^*=\arg\max_{a_1}P_{\mathrm{avg}}(a_1).
$$

MATLAB优化函数一般求最小值，因此可以改写为

$$
a_1^*=\arg\min_{a_1}\left[-P_{\mathrm{avg}}(a_1)\right].
$$

### 计算流程

```text
确定可调参数及其范围
      ↓
确定性能指标：功率、成本、收益或误差
      ↓
给定一组候选参数
      ↓
求解系统模型
      ↓
计算性能指标
      ↓
优化算法更新参数
      ↓
输出最优参数与最优性能
      ↓
稳定性和灵敏度检验
```

### MATLAB框架

```matlab
function P_avg = average_power(a1)

    tspan = [0, 100];
    y0 = [0; 0; 0; 0];

    [t, y] = ode45( ...
        @(t,y) dynamic_model(t, y, a1), ...
        tspan, y0);

    relative_velocity = y(:,4) - y(:,2);
    power = a1 .* relative_velocity.^2;

    % 去掉前半段暂态过程
    index = t >= 50;
    P_avg = trapz(t(index), power(index)) ...
          / (t(end) - 50);
end
```

单参数优化：

```matlab
[a1_best, negative_power] = fminbnd( ...
    @(a1) -average_power(a1), 0, 50000);

P_best = -negative_power;
```

## 4. 先辨识、再优化

实际问题经常同时包含未知物理参数和可调决策参数。例如：

- $m,k,c_w$ 是系统客观参数，需要根据实验数据辨识；
- $a_1$ 是可调阻尼系数，需要使输出功率最大。

完整流程为：

```text
实验数据
   ↓
建立动力学模型
   ↓
以数据误差为目标辨识 m、k、c_w
   ↓
得到经过验证的系统模型
   ↓
以平均功率为目标优化 a1
   ↓
输出最优设计并进行灵敏度分析
```

数学上可以写成两个阶段：

$$
\hat{\boldsymbol\theta}
=\arg\min_{\boldsymbol\theta}
\sum_i\left[
\hat x(t_i;\boldsymbol\theta)-x_i
\right]^2,
$$

$$
a_1^*
=\arg\max_{a_1}
P_{\mathrm{avg}}(a_1;\hat{\boldsymbol\theta}).
$$

## 5. 如何选择寻优算法

| 问题特点 | 建议方法 |
|---|---|
| 单参数、范围明确 | 网格搜索、`fminbnd` |
| 少量连续参数、目标较平滑 | `fmincon`、`lsqcurvefit` |
| 目标函数可能存在多个局部最优 | 多初值、PSO、GA |
| 参数包含整数或离散选择 | GA、整数规划 |
| 参数多且每次模型计算很慢 | 先降维，再使用代理模型或高效局部优化 |

推荐的稳妥策略是：

```text
粗网格或PSO全局搜索
          ↓
确定较好的参数区域
          ↓
fmincon等局部算法精细优化
          ↓
多初值和重复实验检验结果
```

使用PSO或GA前，应通过目标函数曲线、多初值结果或实际约束说明为什么需要全局搜索。只有一个参数且目标函数单峰时，网格搜索或`fminbnd`通常更加清楚可靠。

## 6. 论文必须报告的内容

无论使用哪种方法，论文中至少应说明：

1. 参数的物理意义、单位及取值范围；
2. 目标函数的数学表达式；
3. 选用该优化算法的理由；
4. 初始值、上下界和终止条件；
5. 最优参数和目标函数值；
6. 实测值与预测值对比图；
7. 残差、RMSE、$R^2$等评价指标；
8. 多初值、重复运行或灵敏度分析；
9. 参数变化对最终结论的影响。

核心判断是：

$$
\boxed{
\text{根据数据反推未知参数：参数辨识；}
\quad
\text{根据性能选择可调参数：直接优化。}
}
$$
